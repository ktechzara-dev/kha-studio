# OptiFlow Vision Studio - Third-Party Open-Source Notices

OptiFlow Vision Studio is an original industrial machine-vision IDE built exclusively using permissive open-source libraries. No proprietary SDKs, DLLs, icons, or verbatim code from commercial products are bundled or copied.

This software is offline by default and includes zero telemetry.
