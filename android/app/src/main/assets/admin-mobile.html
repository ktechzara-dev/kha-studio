📱 Hướng dẫn cài đặt App lên màn hình Android

1. Mở trang này bằng trình duyệt Google Chrome trên điện thoại.
2. Bấm vào nút menu (dấu 3 chấm ⋮ ở góc trên bên phải).
3. Chọn "Cài đặt ứng dụng" hoặc "Thêm vào Màn hình chính".
4. Điện thoại sẽ tạo icon Kha Studio Admin độc lập ngoài màn hình chính để sếp mở nhanh bất cứ lúc nào!
